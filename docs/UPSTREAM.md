# 与上游项目的关系

- 上游项目：<https://github.com/liudoge66/ID486-Tarkov-Assistant>
- 上游作者：Liudoge（Bilibili）
- 对比基线：上游 `main` / tag `v0.2`

本仓库是在上游项目基础上进行界面重写与构建工具开发的非官方衍生项目。

## 主要改动

| 区域 | 改动 |
| :--- | :--- |
| 界面 | 用 `ui_compact.py` 重写为固定 464×540 三标签紧凑窗口（V1.2.6 起恢复 V0.7 尺寸） |
| 检测 | 调整战斗 HUD 准入阈值，支持 16:10 与自定义分辨率 |
| 界面识别 | 新增快捷栏 A、页签 B–G/O、控制台 P、游戏主页 Q、设置 S、确认 K、结算 Y 的模板识别与安全白名单 |
| 游戏主页 | `home_Q.png` 提取 `ESCAPE` 字样，在顶部条内按多种位置、纵横比与水平比例匹配，兼容轮换背景 |
| 撤离保护 | 绿色横幅 `N` 确认后自动待机；红色读秒与画面淡出作为第二层保护；结算页 `Y` 在最近 60 秒识别过有效横幅时作为后备保护 |
| 编号 | 界面编号统一为 `TKF-7314-<字母>`，显示在窗口右上角与诊断页 |
| 自动按键 | HUD 就绪后立即按一次，之后按间隔重复；准入线 0.12，失焦或 HUD 消失时暂停并强制松开 |
| 品牌 | 应用名改为「从零开始的塔科夫生活」，支持三套主题名称与配色 |
| 双语 | 新增中文 / English 运行时切换，覆盖界面、状态、日志与音效显示名；V1.2.7 修复 464 px 英文界面语言按钮 |
| 音效 | 5 个预置，支持自定义音频导入、试听、启用 / 静音与持久化 |
| 打包 | 用 `repack_pyz.py` 重排 PYZ，不再受固定槽位限制；`strip_embedded_assets.py` 清理未使用归档 |
| 设置 | 完整保存音效、快捷键、测试模式、分辨率与自动按键配置 |
| 管理员提示 | 首次普通权限启动时提示通过 UAC 提权重启 |

## 上游衍生内容

- `scripts/patch_detector.py` 中的 `normalize_top`、`scores_top` 等替换源码派生自上游 `detector.py`，并按本项目需要修改。
- 基底 EXE、`sound_library` 与 `detector` 的原始实现来自上游项目。
- `assets/interface/` 下的界面模板来自游戏画面，仓库不提供。

这些内容不在本仓库 MIT 许可证的覆盖范围内，详见 [NOTICE.md](../NOTICE.md)。

## 未包含的内容

本仓库不包含：

- 上游或本项目的 EXE；
- 上游 PYZ / marshal 编译产物；
- 第三方音频、图标、字体或游戏素材；
- 界面识别模板。

构建时需要自行准备上游基底 EXE 与模板，见 [BUILD.md](BUILD.md)。
