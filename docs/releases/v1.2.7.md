# 从零开始的塔科夫生活 · V1.2.7

本工具是本地 PvE 战局的 Windows 视觉辅助：只截取屏幕顶部 HUD，不读内存、不注入游戏进程。确认战斗 HUD 后会开始监控；普通情况下，当 HUD 持续缺失达到设定延时，发送一次 **Alt+F4**，然后自动停止监控。识别到顶部绿色「停留在撤离点内」横幅后，程序立即释放自动按键、停止监控并进入待机，**不发送 Alt+F4**，也不会关闭游戏。

> 仅建议在本地 PvE / 离线模式使用。请先确认符合游戏与平台规则；在线模式使用可能违反规则，风险由使用者自行承担。

## 行为说明

### 正常监控

确认战斗 HUD 后开始监控。HUD 持续缺失达到设定延时，发送一次 Alt+F4，然后停止监控。Alt+F4 只发送一次，不自动重试。

### 撤离自动待机

识别到顶部绿色「停留在撤离点内」横幅 `TKF-7314-N` 后，连续约 300 ms 确认，立即释放自动按键并停止监控。窗口保持打开，状态卡显示「待机」；不发送 Alt+F4，也不会关闭游戏。下一局需要重新按 F1。

### 三层撤离保护

1. **绿色横幅**：`N` 确认后直接停止监控并待机。
2. **红色读秒 + 淡出**：如果横幅被遮挡或分辨率差异过大而没有触发待机，读秒 `00` 与画面淡出确认仍会作为第二层保护。
3. **结算页 `Y`**：撤离后的战局结算画面在最近 60 秒内识别过有效撤离横幅时作为后备保护，不会触发 Alt+F4。

死亡 / 失踪结算不会命中 `Y`，仍可能按普通 HUD 缺失逻辑处理。

### 安全界面白名单

已收录的背包、总览、健康、技能、地图、任务、成就、控制台、游戏主页、设置、确认和战局结算等界面都有白名单或后备保护，不会触发 Alt+F4。未收录的菜单、加载或转场仍可能被当作 HUD 缺失，建议先用测试模式验证。

## 使用方法

1. 解压整个「从零开始的塔科夫生活」文件夹，不要只复制 EXE。保持 EXE、`settings.json` 和 `icons` 文件夹在同一目录。
2. 双击「从零开始的塔科夫生活.exe」。首次启动需要解包，可能等待数秒。如果出现管理员权限提示，建议选择「是」，否则 Alt+F4 和自动按键可能被 Windows 权限策略拦截。
3. 建议先勾选「测试模式」，进入本地 PvE 战局，确认血量人形和快捷栏可见后按 **F1** 开始监控。测试模式只记录，不发送 Alt+F4。
4. 观察右上角界面编号和状态卡。确认识别稳定后，取消测试模式，按 F1 开始正常监控。
5. 撤离时看到绿色「停留在撤离点内」横幅后，程序会自动停止监控并待机。这是正常行为，不是崩溃，也不会关闭游戏。
6. 下一局重新按 F1。切出游戏时采集会暂停，回到游戏后自动继续判断。
7. 需要英文界面时点击右上角 `EN`；切回中文点击 `中`。V1.2.7 已确保英文界面下 `中` 按钮始终可见。

快捷键、模式或分辨率修改后，到「进阶设置」点「保存设置」。

## 已知限制

- 仅建议在本地 PvE / 离线模式使用。在线模式可能违反游戏或平台规则，风险由使用者自行承担。
- 本工具只做屏幕像素识别，不读取账号信息，也不保证退出后一定回档或保留装备。
- 检测模板基于 2560×1600、16:10、全屏实测。其他分辨率请在「进阶设置」填写自定义分辨率，并保持独占全屏、客户区等于主屏。
- 如果绿色横幅被遮挡、分辨率差异过大或界面刷新异常，可能无法触发待机；此时撤离读秒、00 判定和淡出确认仍会作为后备保护。
- 死亡 / 失踪结算不会命中撤离保护，仍可能按普通 HUD 缺失逻辑处理。
- 如果横幅、读秒和结算页都没有被识别，中途的黑屏 / 加载画面仍可能被当作 HUD 缺失。
- Alt+F4 与自动按键都是模拟输入，可能被 Windows UIPI、反作弊或权限策略拦截。
- 程序未签名，首次运行可能出现 SmartScreen 提示；请确认文件来源。
- 不要同时运行多个实例；程序使用单实例锁。如果提示「工具已经运行」，请先关闭旧的程序窗口。

## English

**From Zero to Tarkov Life V1.2.7** is a UI-fix release. Detection, extraction standby, auto-key, sound presets and custom-audio behavior are unchanged from V1.2.6.

The 464 px English layout previously pushed the `中` language button out of the header because the long English title, status text and interface badge exceeded the available width. The header now uses a flexible left title plus a fixed right-hand control group containing the language button, status and badge, so the language switch is always reachable. English header statuses are shortened to Idle / Active / Ended while the status card keeps the full text. The window remains the fixed 464 × 540 and is not resizable.

When the green extraction banner is recognized, the tool stops monitoring and returns to standby without sending Alt+F4. The `TKF-7314-Y` settlement page is a fallback protection that only applies when a valid extraction banner was seen in the last 60 seconds.
