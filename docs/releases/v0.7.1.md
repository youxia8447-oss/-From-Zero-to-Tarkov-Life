# 从零开始的塔科夫生活 · v0.7.1

本工具是本地 PvE 战局的 Windows 视觉辅助：只截取屏幕顶部 HUD，不读内存、不注入游戏进程。确认战斗 HUD 后会开始监控；当 HUD 持续缺失达到设定延时，发送一次 **Alt+F4**，然后自动停止监控。

> 仅建议在本地 PvE / 离线模式使用。请先确认符合游戏与平台规则；在线模式使用可能违反规则，风险由使用者自行承担。

## 自定义分辨率

在「进阶设置 → 检测参数 → 分辨率」中填写：

- `auto` 或留空：按自动模式处理，沿用 16:10 检测配置。
- `宽x高`：例如 `2560x1600`、`1920x1080`、`3440x1440`，支持字母 `x` 或乘号 `×`。

填写后点「保存设置」才会写入配置文件；格式错误会提示 `分辨率格式应为 宽x高，如 2560x1600`。

**限制**：采集逻辑仍要求游戏窗口客户区等于主显示器全屏区域。自定义分辨率在游戏使用**独占全屏**、且系统显示分辨率与填写值一致时生效。无边框/窗口化模式请填写与桌面一致的分辨率，或留空使用 `auto`。

## 快速开始

1. 解压后保持 `从零开始的塔科夫生活.exe`、`settings.json`、`icons` 在同一目录。
2. 双击 EXE。首次启动可能需要等待解包；若出现「管理员权限」提示，建议选择「是」。
3. 建议先勾选「测试模式」，进入本地 PvE 战局，确认 HUD、血量人形和快捷栏可见后按 **F9** 开始监控。
4. 观察右上角模式徽标与状态卡「就绪」是否正常。测试模式只记录，不发送按键。
5. 确认识别稳定后，取消测试模式，再按 F9 开始正常监控。
6. 再次按 F9 停止。切出游戏时停止采集；回到游戏后需要重新按 F9。

快捷键、模式或分辨率修改后，到「进阶设置」点「保存设置」。

## 已知限制

- 基础 HUD 识别基于 2560×1600、16:10、全屏实测；其他分辨率请使用自定义分辨率，并确认与游戏实际画面一致。
- 自定义分辨率不改采集区域，仍需独占全屏且客户区等于主屏；无边框/窗口化只支持与桌面同分辨率。
- 游戏以管理员权限运行时，本工具若不是管理员权限，Windows UIPI 会阻止模拟按键和 Alt+F4。
- 自动按键与 Alt+F4 都是模拟输入，可能被反作弊或权限策略拦截。
- 程序未签名，首次运行可能出现 SmartScreen 提示；请确认文件来源。
